# Entre Lendas Pixel

Fonte bitmap original do projeto, desenhada em uma grade de 5×7 pixels com marcas para os acentos do português. `entre_lendas_pixel.fnt` usa o atlas `entre_lendas_pixel.png`. Não depende de fontes instaladas no computador.

Autoria: projeto Entre Lendas (2026). Os glifos foram desenhados para esta interface, sem copiar arquivos de fontes externas.
